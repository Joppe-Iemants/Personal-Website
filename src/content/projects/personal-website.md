## A space to build on

This website is the starting point for my personal space on the internet. It introduces who I am and provides a home for the projects, experiments, and technical writing I share over time.

## Simple by choice

Built with Astro, the site generates static HTML at build time. Plain CSS handles the design, and the pages ship without client-side JavaScript.

Projects and articles live in Markdown content collections. Each new entry gets its own page, keeping the site easy to extend without a database or a content management system.

## The foundation

- Semantic HTML and responsive layouts.
- Page descriptions, canonical URLs, structured data, and a sitemap.
- Static files ready for traditional web hosting.
- A small codebase with reusable layouts and components.
